1. Real-Time Store Management

   Users can:

   - [ ] Add a product (name, price, image).

   - [ ] Edit existing products.

   - [ ] Delete products.

   Updates broadcast in real time to all clients.

2. Chaotic Random Events

   Add periodic randomness (every 60 seconds):

   - [ ] Price Surge: A random product's price increases 10x.

   - [ ] Mystery Buyer: A product gets "purchased" and disappears.

   - [ ] Product Mutation: Names of random products get scrambled.

3. Social Interaction

   Users can:

   - [ ] Like products in real time.

   - [ ] Steal products (randomly assign it under their name).

4. Fun Real-Time Effects

   Use animations to emphasize chaotic events:

   - [ ] Confetti for price surges.

   - [ ] Flickering effects for product mutations.

   - [ ] "Steal" animations showing ownership transfer.
